## 1. Overview and Architecture

This guide walks you through constructing a professional, enterprise-grade Power BI report from scratch using the cleaned retail dataset generated by this project.

### Data Model Architecture:
```
+--------------------+              +-------------------------+
|      Dim_Date      |              |       Fact_Sales        |
+--------------------+              +-------------------------+
| Date (PK)          |<---[ 1 : * ]-| Order Date (FK)         |
| Year               |              | Order ID                |

| Month Name         |              | Product Name            |
```

## 2. Step-by-Step Build Instructions

### Step 2.1: Ingest Cleaned Data
1. Open **Power BI Desktop**.
2. Click **Get Data** -> **Text/CSV** (or **Excel Workbook**).
3. Browse to `data/processed/retail_sales_cleaned.csv` and click **Open**.
4. In the preview dialog, click **Transform Data** to open the **Power Query Editor**.
5. Rename the query on the left pane from `retail_sales_cleaned` to **`Fact_Sales`**.
6. Verify the detected data types:
   - `Order ID`: Text
   - `Order Date`: Date
   - `Product ID`: Text
   - `Product Name`: Text
   - `Category`: Text
   - `Region`: Text
   - `Quantity`: Whole Number (`Int64`)
   - `Unit Price`: Fixed Decimal Number (`Currency`)
   - `Sales Amount`: Fixed Decimal Number (`Currency`)
7. Click **Close & Apply** in the Home ribbon.

---

### Step 2.2: Create the Calendar Dimension Table (`Dim_Date`)
1. In the **Report** or **Model** view, navigate to the **Modeling** tab on the top ribbon.
2. Click **New Table**.
3. Paste the following DAX formula into the formula bar:
   ```dax
   Dim_Date = 
   VAR MinDate = MIN('Fact_Sales'[Order Date])
   VAR MaxDate = MAX('Fact_Sales'[Order Date])
   RETURN
   ADDCOLUMNS(
       CALENDAR(MinDate, MaxDate),
       "Year", YEAR([Date]),
       "Month Number", MONTH([Date]),
       "Month Name", FORMAT([Date], "mmm"),
       "Month Full Name", FORMAT([Date], "mmmm"),
       "Year Month", FORMAT([Date], "yyyy-mm"),
       "Month Year Display", FORMAT([Date], "mmm yyyy"),
       "MonthSort", YEAR([Date]) * 100 + MONTH([Date]),
       "Quarter", "Q" & FORMAT([Date], "q")
   )
   ```
4. **Sort Months Chronologically (Crucial):**
   - Click on the `Dim_Date` table in the Fields/Data pane.
   - Select the column **`Month Year Display`**.
   - In the top ribbon, click **Column Tools** -> **Sort by Column** -> choose **`MonthSort`**.
   - Repeat for **`Month Name`** -> **Sort by Column** -> choose **`Month Number`**.
5. Right-click `Dim_Date` and select **Mark as Date Table** -> Select `Date` as the Date column.

---

### Step 2.3: Establish Model Relationships
1. Switch to the **Model View** (icon with 3 connected boxes on the left navigation bar).
2. Drag `Dim_Date[Date]` and drop it onto `Fact_Sales[Order Date]`.
3. Double-click the relationship line to confirm properties:
   - **Cardinality:** One to Many (`1:*`)
   - **Cross filter direction:** Single (`Dim_Date` filters `Fact_Sales`)
   - **Make this relationship active:** Checked.

---

### Step 2.4: Create a Dedicated Measures Table (`_Measures`)
1. In the Home ribbon, click **Enter Data**.
2. Set the table name to **`_Measures`**, leave Column 1 blank, and click **Load**.
3. In the Data pane, right-click `_Measures` and click **New Measure**.
4. Add the DAX measures detailed in `powerbi/dax_measures.md`:
   - `Total Sales = SUM('Fact_Sales'[Sales Amount])`
   - `Total Orders = DISTINCTCOUNT('Fact_Sales'[Order ID])`
   - `Total Quantity Sold = SUM('Fact_Sales'[Quantity])`
   - `Average Order Value = DIVIDE([Total Sales], [Total Orders], 0)`
   - `Previous Month Sales = CALCULATE([Total Sales], PREVIOUSMONTH('Dim_Date'[Date]))`
   - `MoM Sales Growth % = DIVIDE([Total Sales] - [Previous Month Sales], [Previous Month Sales], BLANK())`
5. Format each measure:
   - Select `Total Sales` -> Format as **Currency**, select `₹ English (India)`.
   - Select `Average Order Value` -> Format as **Currency**, select `₹ English (India)`.
   - Select `MoM Sales Growth %` -> Format as **Percentage** with 2 decimals.
6. Delete the temporary blank `Column1` from `_Measures`.

## 3. Visual Canvas Design & Layout

Use a modern 16:9 canvas (1280 x 720 px) with a light slate background (`#F8FAFC`).

```
+----------------------------------------------------------------------------------------------------+
|  RETAIL SALES & REVENUE PERFORMANCE DASHBOARD                         [Date Slicer: Jan 2025 - Dec 2025] |
+----------------------------------------------------------------------------------------------------+
| [Card: Total Sales]     | [Card: Total Orders]  | [Card: Avg Order Value] | [Card: Quantity Sold]   |
| ₹6,406,050              | 945 Orders            | ₹6,778.89               | 2,750 Units             |
+-------------------------------------------------+--------------------------------------------------+
|  MONTHLY REVENUE TREND (Line & Clustered Column)|  TOP 5 PRODUCTS BY REVENUE (Horizontal Bar)       |
|  - X-Axis: Dim_Date[Month Year Display]        |  - Y-Axis: Fact_Sales[Product Name]              |
|  - Columns: [Total Sales]                       |  - X-Axis: [Total Sales]                         |
|  - Line: [MoM Sales Growth %]                   |  - Tooltip: [Total Quantity Sold]                |
+-------------------------------------------------+--------------------------------------------------+
|  SALES BY REGION (Donut or Column Chart)        |  SALES BY CATEGORY (Donut / Bar Chart)           |
|  - Category: Fact_Sales[Region]                 |  - Category: Fact_Sales[Category]                 |
|  - Values: [Total Sales]                        |  - Values: [Total Sales]                         |
|  - Details: Share %, Orders                     |  - Details: Share %, Units Sold                  |
+----------------------------------------------------------------------------------------------------+
|  INTERACTIVE SLICERS BAR: [Region Filter] | [Category Filter] | [Product Search Slicer]            |
+----------------------------------------------------------------------------------------------------+
```

### Visual Specifications:
1. **Header Banner:**
   - Text box: "Retail Sales Analysis Dashboard" (Font: Segoe UI Semibold 20pt, Dark Navy `#0F172A`).
2. **KPI Cards (Top Row):**
   - Use the **Card** or **New Card Visual**.
   - Card 1: `[Total Sales]` -> Display Units: Auto or Thousands (e.g. ₹64.06L or ₹6.41M).
   - Card 2: `[Total Orders]` -> 945.
   - Card 3: `[Average Order Value]` -> ₹6,778.89.
   - Card 4: `[Total Quantity Sold]` -> 2,750.
3. **Monthly Trend Visual (Center-Left):**
   - Visual Type: **Line and Clustered Column Chart**.
   - Shared X-axis: `Dim_Date[Month Year Display]`.
   - Column values: `_Measures[Total Sales]` (Color: Royal Blue `#2563EB`).
   - Line values: `_Measures[MoM Sales Growth %]` (Color: Crimson Red `#DC2626`).
4. **Top 5 Products Bar Chart (Center-Right):**
   - Visual Type: **Clustered Bar Chart** (Horizontal).
   - Y-Axis: `Fact_Sales[Product Name]`.
   - X-Axis: `_Measures[Total Sales]`.
   - Filter Pane: On `Product Name`, apply **Filter Type = Top N**, set **Top 5**, By Value: `[Total Sales]`.
5. **Regional Sales Distribution (Bottom-Left):**
   - Visual Type: **Donut Chart** or **Clustered Column Chart**.
   - Legend / Axis: `Fact_Sales[Region]`.
   - Values: `_Measures[Total Sales]`.
6. **Product Category Distribution (Bottom-Right):**
   - Visual Type: **Donut Chart**.
   - Legend: `Fact_Sales[Category]`.
   - Values: `_Measures[Total Sales]`.
7. **Interactive Slicers:**
   - **Date Range Slicer:** `Dim_Date[Date]` (Type: Between slider).
   - **Region Slicer:** `Fact_Sales[Region]` (Type: Tile or Dropdown).
   - **Category Slicer:** `Fact_Sales[Category]` (Type: Dropdown).

   - Filtered view by Region / Category.
3. Save screenshots into the `screenshots/` directory of your repository.
